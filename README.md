Trong project này tôi sử dụng HTML, CSS(BootStrap), Javascrip(Ajax, jQuery) để tạo Front-End,
Java(Spring boot) để làm Back-End và quản lý Database bằng: Sql (Mysql).
Trong đó phần Front-End tôi có làm và hoàn thiện chức năng trang quản lý tòa nhà; Backend tôi xây dựng theo MVC layer, 
sử dụng Builder pattern để sử dụng tạo đối tượng với những dữ liệu khác nhau, có sử dụng thêm một lớp converter để chuyển đổi từ Entity sang DTO và ngược lại theo Adapter pattern
Tôi làm project này với mục đích chính học cách cài đặt, xử lý các logic bên dưới, triển khai một chức năng cụ thể và xem các thành phần hoạt động và liên kết với nhau.
Trong Back-End tôi áp dụng 13 quy tắc xây dựng restful APIs để hướng tới clean code
